# SW Müzik Bulucu

Kotlin + Jetpack Compose ile yazılmış Shazam benzeri Android uygulaması. Tanıma altyapısı: AudD.

- Mikrofonla müzik bulma (10 sn kayıt)
- Kayan baloncuk (diğer uygulamaların üstünde, dokununca tanır)
- Link ile müzik bulma (Instagram, TikTok, Twitter, Facebook vb.) ve Paylaş menüsünden gönderme
- Geçmiş (tarihli, silinebilir), Ayarlar (tema, dil, bildirim, izinler, API anahtarı)
- Şarkı detayı: Spotify / YouTube / Apple Music bağlantıları, albüm bilgisi, şarkı sözleri

İlk kullanımda Ayarlar > AudD API anahtarı alanına https://dashboard.audd.io adresinden aldığın anahtarı gir.
